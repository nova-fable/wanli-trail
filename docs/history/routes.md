## 红一方面军 · 中央红军

**于都 → 信丰 → 汝城 → 宜章 → 湘江 → 通道 → 黎平 → 乌江 → 遵义 → 土城（一渡赤水）→ 扎西 → 娄山关（二渡）→ 茅台（三渡）→ 息烽（四渡·南渡乌江）→ 贵阳 → 皎平渡 → 会理 → 冕宁 → 安顺场 → 泸定 → 夹金山 → 达维 → 两河口 → 毛儿盖 → 草地 → 包座 → 俄界 → 腊子口 → 哈达铺 → 六盘山 → 吴起镇**

关键转折：通道转兵（西进贵州）、遵义会议（军事转向）、四渡赤水（机动穿梭）、巧渡金沙江（跳出包围）、彝海结盟（借道彝区）、俄界整编（坚持北上）、哈达铺定向（落脚陕北）。

## 红二方面军 · 红二、六军团

**桑植 → 便水 → 贵阳以南 → 乌蒙山区 → 黔西 → 昆明以北（普渡河） → 石鼓·巨甸（渡金沙江） → 中甸 → 康北（稻城·理塘） → 甘孜 → 哈巴雪山/草地 → 巴西 → 拉界 → 渭水 → 陇东 → 将台堡**

关键转折：便水脱追、乌蒙山回旋（"神来之笔"）、石鼓渡江（四天三夜渡万八千人）、甘孜会师后联袂北上。

## 红四方面军

**苍溪 → 剑门关 → 江油 → 懋功/达维（迎中央） → 松潘西北 → 包座 → 南下再穿草地 → 宝兴/天全（南下） → 百丈关 → 西康甘孜 → 北上草地 → 洮州/岷县 → 会宁**

关键转折：嘉陵江强渡（长征起点）、达维迎中央、包座打开北上通道、百丈关受挫（南下破产）、三过草地（因分裂往返）、会宁收官。

## 补充说明：红十军团（北上抗日先遣队）

红十军团的行动主要是为牵制敌军、配合中央红军转移，活动于闽、浙、赣、皖边，最终在怀玉山遭受重大损失，余部由粟裕、刘英率领转入游击战。**它通常不归入三大主力方面军的长征路线序列**，故沙盘不为其设路线层。

## 红二十五军

**何家冲 → 独树镇 → 庾家河 → 陕南（镇安/华阳/葛牌镇，创建鄂豫陕根据地） → 沣峪口（北上） → 双石铺 → 两当 → 天水北关 → 秦安 → 静宁 → 隆德 → 六盘山 → 泾川四坡村 → 镇原 → 板桥 → 豹子川 → 永坪镇**

关键转折：独树镇生死战、陕南立足壮大（唯一扩红的长征队伍）、**1935 年 7—9 月西进甘肃大迂回**（佯攻西安后突转陇南：两当 08-03、天水 08-09、静宁 08-14、隆德 08-17、翻六盘山 08-18、四坡村 08-21 吴焕先牺牲、经镇原合水北上）、永坪会师（09-15，三日后合编红十五军团）。

> 考证说明：甘肃迂回段乡镇坐标（江口/双石铺/两当/静宁/隆德/镇原/板桥/四十里铺）为县城级近似值；华阳点取 03-10（石塔寺伏击当日）。依据见人民网党史频道《红 25 军开始长征》《西进甘肃迎接党中央》等。

## 时间对齐机制

每个航点带 `date`，运行时按"时刻 t 在相邻航点日期之间线性插值"推进；段内再按弧长比例分配时间，保证小红军沿曲线**匀速行军**。同一天出发/到达的多军（如 1936-10 会师期）在时间轴上自然交汇。
