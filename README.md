# wanli-trail · 红军长征沙盘 · 1934 — 1936

基于真实经纬度 GIS 地图的长征沙盘演示应用：四路红军（红一方面军、红二方面军、红四方面军、红二十五军）1934.10 — 1936.10 全路线，纪录片式自动播放 + 自由探索，直至会宁、将台堡三大主力大会师。

## 功能

- **两种模式**：开场页可选「开始演示」（纪录片式播放，跨越 57 个关键事件自动暂停讲解、镜头飞行跟随）或「自由探索」（直接全览全部路线，自行点击查看）
- **时间轴**：拖动跳转任意日期、0.5× / 1× / 2× / 4× 倍速、事件刻度点可点击直达，实时显示「长征第 N 天」
- **四路红军**：按史实时间依次出发推进，**行走的小红军士兵标记**（扛旗、迈腿摆臂动画、按行进方向转向、到达终点收旗）沿路线插值移动，已走实线 / 未走虚线，图例可切换显隐并显示各军进度
- **57 个关键事件**：出发 / 战役 / 会议 / 会师 / 天险等七类，播放中自动暂停弹出讲解卡（含关联历史人物徽章与长征天数），地图事件标记可点击查看，支持上一事件 / 下一事件翻阅；重点事件在放大到 6 级以上时显示地图名称标签
- **战场态势层**（图例中可分组开关，按时间轴动态显隐）：
  - **红军根据地驻扎**：中央苏区、鄂豫皖、川陕、湘鄂川黔、鄂豫陕、陕甘·陕北六大苏区的存续演变——主力撤离即消隐、陕北苏区作为落脚点始终存在
  - **国民党军围堵**：四道封锁线（突破即消隐）+ 湘军何键、粤军陈济棠、桂军白崇禧、黔军王家烈、滇军龙云、川军刘湘、中央军薛岳/胡宗南、东北军张学良等派系驻防与追剿，含各部立场与作战记述
  - **日军威胁**：九一八事变、一·二八淞沪、长城抗战、华北事变、绥远抗战——呈现"北上抗日"的时代背景
  - 三类标记均带时间窗与信息卡（点击查看）
- **人物志**：顶栏「人物志」收录 22 位关键人物（毛泽东、周恩来、朱德、彭德怀、贺龙、任弼时、徐向前、徐海东、刘志丹、小叶丹等），点击人物直接跳转其首次登场的事件
- **红军兵力消长**（长征精神 · 不怕牺牲）：图例实时显示四路红军人数——于都出发 8.6 万 → 湘江血战后 3 万 → 吴起镇 7 千；四军合计出发约 20.6 万、到达约 5.7 万
- **精神印记**（鱼水情深 · 患难与共）：半条被子、断肠明志、大渡河船工、丰碑、金色鱼钩、七根火柴、一袋干粮、三过草地——8 个故事以金色书签标记在地图对应时间地点，播放经过时弹出提示，点击阅读全文
- **长征诗词字幕**：特定时段在字幕上方浮现金色诗句——《忆秦娥·娄山关》《七律·长征》《清平乐·六盘山》等
- **雪山草地氛围**：翻越夹金山等雪山时飘雪落寒、穿越松潘草地时流雾弥漫，以身临其境传达"风雨侵衣骨更硬"
- **长征精神结语页**：顶栏「★ 长征精神」随时可看；演示播放到将台堡会师后自动呈现——五大长征精神、数说长征（雪山/大河/战斗/牺牲）、毛泽东《七律·长征》全文与"宣言书、宣传队、播种机"论断
- **底图切换**：高德中文政区（默认）/ Esri 世界地形 / OpenStreetMap（部分网络环境不可达），均做仿古羊皮纸化处理
- **镜头跟随**：播放时以飞行过渡 + 指数平滑跟拍部队推进，跟随视野随倍速自适应（1× 省级 / 2×、4× 逐级拉远）；拖动地图自动解除，顶栏可重新开启
- **随行军浮现**（默认）：行军中隐藏未抵达的事件图标，只看路线与行走的小红军，走过即浮现；图例「显示设置」可切换为全部常显
- **连播**：时间轴「⏭ 连播」一键回到 1934 年 10 月，自动播放至大会师并呈现长征精神结语（不逐事件暂停）
- **江河要津**：湘江、乌江、赤水、金沙江、大渡河等十条大江大河以青蓝双色衬底突出（简化示意走线），可在战场态势中开关
- **事件总览**：顶栏「事件总览」弹出 57 个事件索引（按部队筛选、已发生着色），点击条目跳转该日期并讲解
- **偏好记忆**：底图、倍速、讲解/跟随开关、图层显隐、图例折叠状态自动保存（localStorage），刷新不丢
- **操作指南**：开场页有要点提示；地图右下「?」按钮查看快捷键与交互规则（`Esc` 关闭）
- **无障碍与窄屏**：时间轴可键盘操作（`←`/`→` 前后七天、`空格` 播放/暂停），列表项均可聚焦；≤768px 自适应布局
- 快捷键：`空格` 播放/暂停，`←`/`→` 前后七天，`Esc` 逐层关闭浮层，开场页 `回车` 开始演示

## 数据说明

- 航点与事件坐标为**手工整理的近似考证值**（省级精度），行军路线沿大方向串联关键史实地点，用于沙盘演示足够，但不适合精确地理分析；所有坐标集中在 `src/data/`，便于校正。史实考据依据见 [docs/history/](docs/history/)。
- 高德底图为 GCJ-02 坐标系，与 WGS84 航点存在数百米偏移，在全国/省级缩放下不可见。
- 史称里程（二万五千里等）为常量展示；图例中的进度按地图测算里程计算。
