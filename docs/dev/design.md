# 设计语言 · 指挥舱 + 羊皮纸档案

> 全部样式单源在 `src/styles/global.css`；本文解释"为什么长这样"与 token 用法。

## 双层概念

**深藏青指挥舱 UI + 仿古羊皮纸地图**：界面是现代的"作战指挥舱"（深色玻璃面板、金色数据、精确刻度），地图是被"研究的历史档案"（宣纸质感、墨色路线、仿古地名签）。两层对比让"今天的我们"与"1934 年的行军"同框。

## 设计 token（:root）

| token | 值 | 用途 |
|---|---|---|
| `--accent` | #d4a94e | 交互金：按钮描边/高亮/播放头 |
| `--accent-soft` | #e8b04a | 数据金：数字/年份/统计 |
| `--gold-deep` | #c9922e | 材质金：徽记/星章渐变端点 |
| `--red` / `--red-deep` | #e53935 / #8e1c1c | 主色族：路线红/按钮红/事件卡顶线 |
| `--radius-panel` / `--radius-ctrl` | 12px / 10px | 面板圆角 / 控件圆角 |
| `--shadow-panel` | 0 8px 30px rgba(0,0,0,.5) | 面板统一阴影 |
| `--line` / `--line-soft` / `--line-strong` | #2d3644 / #232b37 / #3a4452 | 三级描边 |
| `--serif` / `--sans` | 宋体族 / 黑体族 | 标题-日期-数字-诗词-徽记用宋体；正文-控件用黑体 |

新增样式先找 token，找不到先补 token 再用；禁止散落硬编码色值（金色尤其）。

## 羊皮纸地图

- 三种底图（高德/Esri/OSM）共享同一暖色偏移滤镜（sepia 0.38–0.5 + `hue-rotate(-6deg)`、相近饱和度），切换时"同一张宣纸"观感连续。
- `.parchment-fx` 叠加暖色蒙版（multiply）+ 径向暖晕 + SVG feTurbulence 噪点，构成纸面质感；开场页/结语页复用同一噪点 dataURI 衔接材质。
- 地图元素全部"档案化"且为**手绘军用地图符号**（不规则图形、无圆形底托）：事件点按类型取七种轮廓——出发三角旗/战役盾形/会议八角印/会师五角星/天险双峰山形/到达下指锚镞/根据地城垛，类型色半透明填充（fill-opacity 0.52）透出底图、宋体单字白字墨边居中；国民党军为燕尾旗（旗杆底端锚定驻地）、日军为放射芒星（外层光束缓脉冲）；地名签为米黄胶囊深褐字；路线方向箭头用"奶油底衬 + 深墨投影"保证浅底分离度。

## 地图元素视觉层级

1. **行军路线**（4 色 + 白衬底 + 流动虚线）——永远的主角
2. **行军小红军**（SVG 组合人物，摆臂/倾角/到达态，臂章显示部队简称）
3. **当前讲解事件**（ev-pop 弹跳，唯一的强循环动画）
4. **已发生事件点 / 地名签**（米黄胶囊，zoom≥6 常驻重点事件）
5. **态势实体**（苏区色域/封锁线/敌方单位/日军脉冲/精神书签——静态或弱脉冲）
6. 罗盘、比例尺（右下角，档案工具）

动画纪律：全屏最多一个强循环动画（当前事件弹跳）+ 路线流动虚线；其余标记一律静态或 :hover 反馈。

## 全宽时间带

- 贴底横贯屏幕：上排（播放/倍速/提示/日期）、下排（50px 轨道）。
- 刻度尺：月度小刻度 + 年份大刻度（1934.10 起）；事件点双色（已发生=类型色发光、未发生=珍珠白），相邻 <1.25% 自动上下错排防粘连。
- 播放头：金色指针 + 顶部日期气泡随播放头联动；悬停另有日期气泡与事件预览卡。

## 无障碍与响应式

- 列表项一律 `<button>`（可聚焦、可键盘激活）；时间轴 `role="slider"` 支持 ←/→ 前后七天；金色 `:focus-visible` 焦点圈统一。
- ≤768px：顶栏横滑、面板收窄让位、指北针隐藏、字幕缩号、初始视野按窄屏预留。
