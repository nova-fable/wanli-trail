# 国际化（i18n）规范

> 引擎：`src/core/i18n/`（零依赖，约 60 行）；语言状态单例 + `t()` 取词。

## 架构

- **列式词典**：`zhCN.js` 基础键源（全部 UI 键）+ 一语言一文件（`en.js` Partial 起步）+ `index.js` 引擎。
- **回退链**：当前语言缺键 → 中文 → 键名本身（dev 下键名即缺键信号）。
- **响应式**：`state.lang` 为 reactive 单例；组件渲染期调用 `t()` 自动建立依赖，切换语言全站即时刷新。
- **持久化**：语言偏好由 `usePrefs` 代管（键 `lang`，随偏好包落盘）。
- **占位符**：`{name}` 语法，`t('ep.day', { n: 5 })`。

## 键的边界（重要）

| 层 | 是否键化 | 说明 |
|---|---|---|
| UI chrome（按钮/标题/提示/图例/帮助/结语页框架） | ✅ 全部 `t()` | 词典即唯一文案源 |
| 史实数据内容（事件讲解词/人物/故事/诗词/阶段字幕/态势描述/地名） | ❌ 中文单源 | 翻译需专业史实审校，机翻会失真；待专业译稿后按同结构扩展 |
| 语言自称（"中文"/"EN"） | ❌ 字面量 | 目标语言自称不进词典 |

## 扩展新语言（三步）

1. `core/enums` 的 `LANG` 加语言码
2. 新建 `core/i18n/<lang>.js`（Partial 起步，缺键回退中文）
3. `core/i18n/index.js` 的 `DICTS` 注册 + `LANGS` 加切换器选项

## 新增文案键（两步）

1. `zhCN.js` 加键（唯一必做项）
2. `en.js` 同键补译（可滞后，回退不报错）

## 组件用法

```js
const { t, lang: langState, setLang, langs } = useI18n()
```

模板直接 `{{ t('key') }}` / `:title="t('tip.x')"`；数组型键（如 `intro.tips`）`t()` 返回原数组，`v-for` 即用。
